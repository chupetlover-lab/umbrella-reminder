# Surgical Skill Tracker

外科医が自身の手術技術を継続的に振り返り、向上させるための個人用トラッキングアプリです。

## 主な機能

- **症例ログ** — 執刀した症例ごとに、OSATS (Objective Structured Assessment of
  Technical Skill) の評価領域を参考にした7項目の技術自己評価(組織の扱い・時間と動作・器具の扱い・助手の活用・
  手術の流れ・術式知識・総合評価)を記録し、良かった点/改善点/次回への具体的アクションを振り返ります。
- **練習・トレーニング記録** — 結紮・縫合、腹腔鏡ボックストレーナー、シミュレーターなどの反復練習
  (deliberate practice)を記録し、継続日数・練習頻度を可視化します。
- **進捗ダッシュボード** — 症例ごとの総合スコア推移、直近5件とそれ以前のスキルプロファイル比較(レーダーチャート)、
  分野別症例数、週別練習時間をグラフで確認できます。
- **目標** — 具体的で測定可能な技術目標を設定し、進捗をメモします。

データはブラウザの `localStorage` にのみ保存され、外部には送信されません。**患者を特定できる情報は入力しないでください。**
「バックアップ書き出し」からいつでも JSON ファイルとしてデータをエクスポート/インポートできます。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド
```

Vite + React + TypeScript + Tailwind CSS + Recharts で構築しています。
